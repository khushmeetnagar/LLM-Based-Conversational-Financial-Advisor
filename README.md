# LLM-Based Conversational Financial Advisor

## Project Overview

This is a desktop application developed using Python, CustomTkinter, and MySQL. The project helps users manage their personal finances by tracking income, expenses, savings, and providing AI-based financial suggestions.

##  Technologies Used

- Python
- CustomTkinter
- MySQL
- bcrypt
- Git & GitHub

## Features Completed

- User Registration
- Secure Login Authentication
- Password Hashing
- MySQL Database Integration
- Dashboard UI

## Features Under Development

- Expense Management
- Analytics
- Investment Goals
- AI Financial Advisor
- Reports & Charts
